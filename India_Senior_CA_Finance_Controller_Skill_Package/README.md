# India Senior CA & Finance Controller Skill Package

A modular Markdown skill package for Antigravity IDE or another agent environment that supports skill instructions and reference files.

## Files
- `SKILL.md`: main entry point and operating rules
- `references/research-protocol.md`: current-law research workflow
- `references/accounting-and-bookkeeping.md`
- `references/income-tax.md`
- `references/gst.md`
- `references/tds-tcs.md`
- `references/mca-companies-roc.md`
- `references/audit-and-controls.md`
- `references/corporate-finance.md`
- `references/payables-receivables.md`
- `references/output-templates.md`
- `references/regulatory-research-checklists.md`

## Suggested installation
For a project-level skill, place the folder under the repository's supported skill directory, commonly `.agents/skills/india-senior-ca-finance-controller/`. Preserve `SKILL.md` at the root and the `references/` folder. Confirm your installed Antigravity version's discovery conventions.

## Example requests
- Review GST reconciliations for a specified period and list mismatches.
- Prepare a current compliance calendar with official citations.
- Review the trial balance and prepare a month-end close exception report.
- Compare cash-flow scenarios using supplied management data.
- Research TDS treatment for a specified payment and date.

No accounting software, bank, or tax portal integrations are configured. This is not legal advice, CA licensure, statutory certification, or a guarantee of correctness. Current rules must be researched for each time-sensitive issue. A qualified professional should review high-risk positions and statutory submissions.
