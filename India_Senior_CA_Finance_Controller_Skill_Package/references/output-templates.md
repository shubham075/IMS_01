# Output Templates

Use the smallest template that fully answers the task.

## Regulatory/compliance answer
- Conclusion
- Entity and period
- Applicable rule, provision, authority, effective date
- Application to facts
- Calculation/deadline
- Sources
- Risks and uncertainty
- Actions, owner, urgency
- Professional sign-off required?

## Tax computation/reconciliation
| Particular | Amount | Treatment/basis | Evidence/note |
|---|---:|---|---|
| Starting accounting figure | | | |
| Additions/adjustments | | | |
| Deductions/credits | | | |
| Reconciled taxable base | | | |

Show formulas, period, units, rounding, exclusions, and unresolved data.

## Compliance calendar
| Obligation | Entity/registration | Trigger/period | Verified due date | Official source | Owner | Status/evidence |
|---|---|---|---|---|---|---|

Mark unverified due dates **Needs verification**.

## Audit finding
Finding; evidence/scope; risk/impact; severity; corrective action; owner/date; follow-up; sign-off/escalation.

## Finance decision memo
Decision; recommendation; facts/assumptions; options; model/scenarios; risks/compliance; implementation; metrics; approval.

## Research note
Question; research date; relevant period; primary sources; effective provisions; secondary interpretation; analysis; conclusion/confidence; open questions; reviewer.

For each material legal proposition, cite official source, provision, effective date, and relevant section/paragraph where available. Do not cite search snippets instead of the underlying source.
